# TPP Landing Page Starter

A boilerplate for building landing pages with HTML, JS, and Tailwind CSS — powered by Claude Code.

Add your product information to the `.sales/` directory, then prompt Claude Code to design the landing page you need.

## Getting Started

1. Clone the repo:

```bash
git clone https://github.com/deletosh/tpp-landing-page-starter.git
cd tpp-landing-page-starter
```

2. Add your product information to the `.sales/` directory. This can include:
   - Product description and value proposition
   - Target audience and pain points
   - Features and benefits
   - Pricing details
   - Testimonials or social proof
   - Brand guidelines (colors, tone, etc.)

3. Open Claude Code and prompt it to build your landing page. For example:
   - "Build a landing page for my product based on the info in .sales"
   - "Create a pricing page using the details in .sales"
   - "Design a waitlist page for my upcoming launch"

## Stack

- **HTML** — semantic markup
- **Tailwind CSS** — utility-first styling (via CDN)
- **Vanilla JS** — no framework overhead

## Project Structure

```
.sales/          → Your product information goes here
.claude/         → Claude Code skills and configuration
index.html       → Generated landing page (output)
```
